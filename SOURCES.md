### 確認と採用の方針

- MPRGの年別業績一覧、中部大学の教員業績、DBLPを照合し、出版社・学会・著者公開の論文PDFや共著者の業績ページで補完しました。
- 著者に山下隆義 / Takayoshi Yamashitaが含まれる文献を対象としています。タイトルと著者を確認し、同じ刊行版を重複登録しないよう整理しています。
- 論文誌・会議・ワークショップを区別しています。雑誌にはサーベイ・解説記事も含みます。
- 会議は開催年、雑誌は正式巻号の刊行年を採用しました。正式巻号のない先行公開はその旨を掲載誌欄に示しています。
- 正式刊行版と重なるarXivは別件に数えていません。正式proceedings非収録の拡張要旨・発表は今回の新しい論文一覧に含めていません。
- 研究分野の分類と紹介文は、公開論文の内容に基づく編集上の整理です。全研究業績を網羅する一覧とはしていません。

### 主な書誌上の補正

- ACCV 2024のFaster convergence論文はCVF正式ページ・PDFの5名の著者を採用しました。
- VISAPP 2024のDiverse Data Selection論文は、研究室HTMLで抜けているNaoki Okamotoを正式PDFに基づき含めました。
- VISAPP 2026のAdaptive IG-ODAMは出版社の正式タイトルと年を採用しています。
- IV 2025の枝刈り論文は正式題名「Weight Pruning to Mitigate Class-Specific Accuracy Degradation for LiDAR-Based 3D Object Detection」で収録しています。
- Efficient Action Spottingは2023年の先行公開年ではなく、正式巻号の2024年で収録しています。
- Advanced RoboticsのAutomatic data collectionとIEEE Transactions on Intelligent VehiclesのUtilizing Human Social Normsは、研究室の登録年2022ではなく正式巻号の2023年を採用しています。
- ICCE 2021のPerformance PredictionはHTML書誌の3名ではなく、正式PDFに掲載された5名の著者を採用しています。
- Learning from AIの著者順は著者公開原稿等に従っています。BMVC 2023論文のSpatio-Temproalという綴りは正式PDFの題名に従っています。
- ICPR 2026、TSD 2025、IACSS 2023はSpringerの書籍刊行年と会議年が異なります。一覧では会議開催年を使っています。
- YUKUIv2はJ-STAGEの2026年6月15日先行公開を確認し、Advance Publicationと表示しています。
- Normal-Variation-Aware論文のDOIは採録済み著者版のCitation informationを採用しています。原稿に残るテンプレート用DOIとは区別しています。
